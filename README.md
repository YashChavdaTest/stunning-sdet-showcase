# Yash Chavda portfolio

A static, responsive portfolio built with Astro for GitHub Pages. Content and visual direction are based on the supplied portfolio PDF.

## Development

Use Node.js 24 and run `npm ci`, then `npm run dev`. Run `npm run build` to generate the static site in `dist`, and `npm run preview` to inspect the production build locally.

The GitHub Actions workflow builds pull requests and deploys pushes to `main` to GitHub Pages. The site uses the root URL of the GitHub Pages user site.

Certification artwork: ISTQB certification logos are sourced from [ISTQB](https://istqb.org/); Claude certification badges are sourced from [Anthropic on Credly](https://www.credly.com/organizations/anthropic/badges); the Scrum Alliance issuer logo is sourced from [Scrum Alliance](https://www.scrumalliance.org/). Logos and badges belong to their respective owners.
